# XPAYR Team Profile

XPAYR builds non-custodial payment and agent-commerce infrastructure designed around explicit authorization, verifiable settlement, and developer-friendly integration.

## Burak OLGUN

- **Role:** CEO & Full-Stack Developer
- **Nationality:** Türkiye

### Relevant experience

Burak leads XPAYR's product architecture and contributes hands-on across the full delivery stack: PHP and SQL backends, REST APIs, merchant-facing interfaces, JavaScript and Node.js tooling, SDKs, secure webhooks, payment reconciliation, Solidity/EVM smart contracts, automated testing, and release operations.

His recent work includes XPAYR Verified AgentPay for GIWA, a GIWA Sepolia testnet MVP that combines Dojang address verification, policy-controlled AI-agent spending, non-custodial escrow, human-authorized release and refund flows, canonical receipt verification, and signed, on-chain-anchored evidence. The public package includes reproducible release and refund lifecycles, a sealed reviewer bundle, automated tests, and explicit testnet and security boundaries.

Across the broader XPAYR and Web3Cart product portfolio, his work focuses on converting blockchain payment primitives into usable merchant and developer workflows: scoped API authorization, transaction and event verification, checkout and dashboard experiences, webhook safety, evidence-driven reconciliation, and integrations that keep custody and production activation behind explicit controls.
