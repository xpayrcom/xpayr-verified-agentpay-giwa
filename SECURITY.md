# Security Policy

This repository is a GIWA Sepolia testnet reviewer package. Do not send real customer funds, production secrets, or mainnet assets to any address or interface described here.

The implementation's trust boundaries, known limits, reporting guidance, and testnet-only policy are documented in [reviewer-package/SECURITY.md](reviewer-package/SECURITY.md) and [reviewer-package/THREAT_MODEL.md](reviewer-package/THREAT_MODEL.md).

Use GitHub private vulnerability reporting if it is available for this repository. Otherwise, open only a non-sensitive issue requesting a secure contact route. Do not place an unpatched exploit, private key, credential, or personal data in a public issue.
